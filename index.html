Selected Projects

Voice-Controlled Navigation and Manipulation on Unitree Go2-W
  • Perception: YOLO11 object detection with a wrist-mounted depth camera, plus 2D-to-3D coordinate transformation to locate the target in the world frame.
  • Navigation: SLAM-based autonomous navigation to the target position.
  • Language: a task planning pipeline with ASR, LLM, OpenClaw and TTS, so the robot can be controlled by natural language and reply by voice.
  • Manipulation: a grasping pipeline based on forward/inverse kinematics and Jacobian-based motion control.
  • Developed in ROS 2, tested in MuJoCo simulation and on the real robot.
AKI Humanoid Robot
  • Real-time control loop for locomotion and interaction: an RL policy generates joint positions, a joint target layer does scaling, integration and clipping, and a PD layer drives the motors.
  • ASR–LLM–TTS pipeline for natural voice interaction.
Voice RAG Assistant on AgiBot Lingxi X2
  • An in-store retail assistant: customers ask about products, plans, and pricing by voice.
  • Built a fully offline pipeline on a Jetson for events with unreliable networks: a bridge node streams the X2's microphone audio to a local FastAPI backend, which runs local ASR (FunASR/Paraformer-zh), a local LLM (Qwen2.5-7B via Ollama), pgvector RAG over the product database (PostgreSQL), and local TTS (Sherpa-ONNX / Piper).
