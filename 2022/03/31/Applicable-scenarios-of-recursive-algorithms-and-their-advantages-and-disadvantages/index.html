When to use recursive algorithms?

Posted on 2022-03-31 | In Java | Views
CS1103 Discussion Assignment Unit 2.

Questions

When should you consider using recursive algorithms when writing a program? Discuss in terms of advantages and disadvantages.

1. Definition of recursion

“A recursive method is a method that calls itself” (Seiter & Palmer, 2019). A recursive method usually consists of two parts: one is the base case, which halts the recursion; the other is the recursive call, that is, calling the method itself inside the method. “Every recursive method must have at least one base case” (Seiter & Palmer, 2019). If a recursive method has no base case, then the recursion is called infinite recursion. This method will call itself repeatedly until the program eventually crashes.

2. Scenarios suitable for using recursive algorithms

“Recursion is most useful when it is used to solve problems where the structure of the problem repeats” (Seiter & Palmer, 2019). For example, we can use recursion to calculate Fibonacci numbers, which is defined by the recurrence relation: f0 =0; f1 =1; fn = fn-1 + f n-2, for n>1.

According to Seiter & Palmer, “any recursive solution could be written with iteration (loops) instead” (2019). So, in what scenarios is recursion used, and what problems are suitable for iteration? Generally speaking, “iteration is usually preferred and more efficient, but recursive solutions can be elegant and require less code” (Downey & Mayfield, 2019, p. 127).

This is the disadvantage of recursion.

3. In Conclusion

In general, recursion is more elegant and requires less code than iteration, but in some cases, it may take longer to run because recursion requires a lot of call stacks. Hence, if we seek code simplicity, recursion may be a better choice than iteration; if we pursue a faster running time, iteration may be better than recursion.
