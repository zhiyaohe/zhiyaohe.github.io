CS1101 Discussion Assignment Unit 2 - Argument, parameter, value, variable, and expression

Posted on 2022-01-24 | In Python | Views
CS1101 discussion assignment unit 2.

Questions

Create your own Python code examples that demonstrate each of the following. Do not copy examples from the book or any other source. Try to be creative with your examples to demonstrate that you invented them yourself.

Example 1: Define a function that takes an argument. Call the function. Identify what code is the argument and what code is the parameter.

Example 2: Call your function from Example 1 three times with different kinds of arguments: a value, a variable, and an expression. Identify which kind of argument is which.

Example 3: Create a function with a local variable. Show what happens when you try to use that variable outside the function. Explain the results.

Example 4: Create a function that takes an argument. Give the function parameter a unique name. Show what happens when you try to use that parameter name outside the function. Explain the results.

Example 5: Show what happens when a variable defined outside a function has the same name as a local variable inside a function. Explain what happens to the value of each variable as the program runs.

1. Example 1

Question:
Define a function that takes an argument. Call the function. Identify what code is the argument and what code is the parameter.

Codes:

Identification:
hello is the argument; para is the parameter.

Explanation:
Parameter: “A name used inside a function to refer to the value passed as an argument” (Downey, 2015, p. 26).

Argument: “A value provided to a function when the function is called. This value is assigned to the corresponding parameter in the function” (Downey, 2015, p. 26).

In short, parameter is a variable, and argument is a value. “hello” is a value, so it is the argument. para is a variable in the function, so it is the parameter.

2. Example 2

Question:
Call your function from Example 1 three times with different kinds of arguments: a value, a variable, and an expression. Identify which kind of argument is which.

Codes:

Identification:
2021 is a value; vara is a variable; 1*2+3 is an expression.

Explanation:
Value: “One of the basic units of data, like a number or string, that a program manipulates” (Downey, 2015, p. 7).

Variable: “A name that refers to a value” (Downey, 2015, p. 14).

Expression: “A combination of variables, operators, and values that represents a single result” (Downey, 2015, p. 14).

In detail, 2021 is a number; vara is a variable defined by me, and its value is the string “good”; 1*2+3 is an expression, which is a combination of operators and numbers.

As we can see, the result is 100. But 100 is the value of the variable grades outside the function test(), not the value of the local variable grades inside the function test().

“Python program has its flow of execution, execution always begins at the first statement of the program” (Downey, 2015, p. 21). The interpreter first executes the test function in the first line, but does not enter the function, and executes the statement grades = 100. This is because the test function is not called. Therefore, the local variable grades is not created and assigned. After the line of code is executed, the assignment statement grades = 100 outside the function will be executed. At this time, the variable grades will be created and assigned a value of 100. Finally, the print function is executed, and we can see the value of 100 on the screen. But note, this 100 is the value of the variable outside the function, not the value of the local variable inside the function.
