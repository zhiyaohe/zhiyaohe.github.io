CS1103 Programming Assignment Unit 7 - A web server

Posted on 2022-04-04 | In Java | Views
CS1103 Programming Assignment Unit 7.

Questions

Please write a web server that is capable of sending files to a web browser on request. The web server creates a listening socket and accepts connections. It implements just enough of the HTTP/1.1 protocol to enable it to read requests for files and to send the requested files. It is also capable of sending error responses to the client when appropriate.

1. Instructions for use

To test this program, you need to change the value of variable rootDirectory in the code to the directory where you store the test files. I use “F:” in my code, and you can change it. Then put the test files in the directory you choose, and then enter the corresponding URL in the browser, for example, using http://localhost:50505/text.txt to ask for a text.txt file from the server. Besides, you can find the test files in the attachment, which contains a text.txt file and a directory with an index.html.
